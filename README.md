## 📖 About This Repository

This is a **complete, hands‑on Machine Learning course** built as a series of Jupyter‑ready Markdown files and Python notebooks.  

Inspired by the  **StatQuest** series, this course transforms abstract ML concepts into **executable code**. Every chapter combines:

- ✅ Clear, intuitive explanations (just like StatQuest)
- ✅ **Ready‑to‑run Python code** (NumPy, scikit‑learn, TensorFlow)
- ✅ Visualisations that build intuition
- ✅ Practical exercises with real datasets
- ✅ End‑of‑chapter mini‑projects to reinforce learning

Whether you're a beginner or brushing up, this repository will take you from "What is ML?" to building and evaluating Neural Networks – all while writing code yourself.

---

## 📂 Course Structure

The course is organised into **13 folders** – one for each major topic. Each folder contains a detailed `.md` file (or `.ipynb` notebook) with theory, code, and exercises.

| Folder | Topic | What You'll Learn |
| :---: | :--- | :--- |
| `01_Fundamental_Concepts` | **Fundamental ML Concepts** | Classification vs Regression, Overfitting, Train/Test, Independent/Dependent Variables |
| `02_Cross_Validation` | **Cross Validation** | k‑fold, stratified CV, hyperparameter tuning with `GridSearchCV` |
| `03_Statistics` | **Fundamental Statistics** | Mean, variance, distributions, hypothesis testing, CLT |
| `04_Linear_Regression` | **Linear Regression** | OLS, normal equation, `statsmodels`, residual analysis |
| `05_Gradient_Descent` | **Gradient Descent** | Batch, SGD, mini‑batch, learning rates, momentum |
| `06_Logistic_Regression` | **Logistic Regression** | Sigmoid, cross‑entropy, decision boundaries, multiclass |
| `07_Naive_Bayes` | **Naive Bayes** | Gaussian, Multinomial, Bernoulli, Laplace smoothing |
| `08_Model_Performance` | **Assessing Performance** | Confusion matrix, Precision/Recall, ROC‑AUC, regression metrics |
| `09_Regularization` | **Regularization** | Ridge (L2), Lasso (L1), Elastic Net, coefficient paths |
| `10_Decision_Trees` | **Decision Trees** | Gini/entropy, pruning, visualisation, feature importance |
| `11_SVM` | **Support Vector Machines** | Maximal margin, soft margin, kernels (RBF, polynomial) |
| `12_Neural_Networks` | **Neural Networks** | Perceptron, backprop, Keras/TensorFlow, dropout, batch norm |
| `13_Appendices` | **Appendices** | Preprocessing, PCA, ensembles (Random Forest, XGBoost), pipelines |
